# lua-doc-extractor

Rust rewrite of [lua-doc-extractor](https://github.com/rhys-vdw/lua-doc-extractor), to be released
as v4. It reads Lua doc comments in [RecoilEngine](https://github.com/beyond-all-reason/RecoilEngine)'s
C++ source and generates a Lua library for
[emmylua-analyzer-rust](https://github.com/EmmyLuaLs/emmylua-analyzer-rust).

Status: spike. The plan is in
[lua-doc-extractor-rs-spec](https://github.com/rhys-vdw/lua-doc-extractor-rs-spec)
(`IMPLEMENTATION.md`).
